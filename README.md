# MariaGame

Nyt Unreal Engine-spilprojekt.

## Engine
- Unreal Engine 5.8
- C++ / Blueprints

## Repository
Dette repository indeholder kildekode, konfiguration og versionsstyrede Unreal-assets til MariaGame.

## Lokal opsætning
```powershell
git clone https://github.com/phenixdk2020/MariaGame.git
cd MariaGame
```

Åbn derefter `MariaGame.uproject` i Unreal Engine.

## Struktur
- `Config/` – Unreal-konfiguration
- `Content/` – spilassets og Blueprints
- `Source/` – C++-kode
- `Docs/` – design- og projektdokumentation

Store genererede Unreal-mapper som `Binaries`, `DerivedDataCache`, `Intermediate` og `Saved` versionsstyres ikke.
